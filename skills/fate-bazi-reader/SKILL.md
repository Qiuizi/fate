# 八字命盘解读（fate 导出）

> 此文件由 `npm run gen:ai-skill` 从 `src/lib/aiExport.ts` 生成，规则与网页「复制给 AI」完全同源，请勿手改。

## 何时使用

- 用户贴来以「# 八字命盘解读」或「# 八字合盘解读」开头的文本，或 `schema` 为上述值的 JSON。
- 用户只给出生时间、没有命盘：请他先在 fate 里排盘后导出——**不要自己排盘**，四柱、大运、真太阳时与节气交界都容易算错。

## 规则

1. **不要重新排盘。** 四柱、藏干、十神、大运、流年都已由程序按「计算口径」算好，以给出的数据为准；觉得可疑只指出疑点，不要改盘或换算。
2. **只用给出的数据。** 数据里没有的神煞、格局名、关系不要补算；缺的信息写「数据未提供」，或放进最后的「想向你确认的问题」。
3. **每条判断注明依据**（哪一柱、哪个十神或藏干、哪步大运、哪一年），例如「（依据：月柱正官透干 + 日支藏财）」。
4. **分清事实与推断**：【盘面事实】是数据里直接可查的；【推断】要写出推理链并标把握（高 / 中 / 低）——只有两条以上互相独立的依据同向时才可标「高」。
5. **信号冲突要说出来**：旺衰、格局、调候、合冲互相矛盾时，写明你优先哪一个、为什么，不要折中带过。
6. **干支关系只表示「存在」**：数据列出的合、冲、刑、害不等于已经合化或成局；是否化、化得成不成，要你结合月令判断并写出依据。
7. **十二长生分清归属**：「星运」是日主在该地支的状态，「自坐」是该柱天干在本支的状态，不要混用。
8. 「应用参考」里的旺衰、格局、喜用是简法评估，可以不同意，但要写出理由；多种解释都合理时并列写出，说明各自成立的条件。
9. **说人话、说具体**：术语后面跟一句白话；不写对谁都成立的话（如「性格时而外向时而内向」「事业有起有落」「注意身体」），建议要能落到行动。
10. **不绝对化**：不说「必然」「注定」「一定会」；不做医疗诊断，不给具体投资或法律建议，健康只谈作息保养，必要时建议就医。
11. 若「计算口径」里有临界提醒，先提醒命主核实出生时间，并说明哪些结论会随之改变。
12. 先只依据命盘独立分析，不猜测、不迎合命主经历；命主之后补充的经历，用来逐条核对（命中 / 部分命中 / 未命中 / 未知），并说明哪些判断因此要修正。

合盘另加一条：不下「合适 / 不合适」「能不能结婚」之类的结论，只说明互动模式与相处建议；写明「甲方」「乙方」及对应柱位。

## 输出结构（单人完整解读）

1. 一句话结论：先用一两句话概括这张盘的主线，再给 3–5 个关键词
2. 用神推导链：按「旺衰依据（得令 / 得地 / 得势）→ 格局 → 调候 / 病药 → 喜用忌」一步步写，每步引用数据；与「应用参考」不同处写明理由
3. 性格：结合十神与五行配置
4. 事业：适合的方向与工作方式
5. 财：求财方式与需要留意的地方
6. 感情：相处模式与婚恋倾向（不对具体对象下结论）
7. 健康提示：五行偏枯对应的作息、保养提示（非医疗诊断）
8. 大运节奏：按大运切片，重点写上一步、当前、下一步的主题；交运年单独点出
9. 流年时间表：按下方「流年时间表」逐年一句（主题 + 依据），今年多写几句
10. 想向你确认的问题：3–5 个能帮助校准判断的问题（例如某几年的重大变化）
11. 自检：最后用一行列出 ① 是否改动过任何干支 ② 是否每条判断都有依据 ③ 把握为「低」的结论有哪些

## 问题导向与追问

- 用户带着具体问题（事业 / 感情 / 某一年）时：先给结论，只展开相关部分，依据照写，不必输出全部小节。
- 追问一律以同一张命盘为准；用户补充真实经历后，逐条标「命中 / 部分命中 / 未命中 / 未知」，并说明哪些判断要修正。
- 隐私模式（`privacy` 不为 `none`）下不要追问具体生日、时刻或地点。

## JSON 字段速查

| 字段 | 含义 |
| --- | --- |
| `subject` | 性别（乾造 / 坤造）、生肖；非隐私模式另含录入时间、农历、地点、星座 |
| `dayMaster / monthCommand` | 日主天干五行阴阳；月令地支及所在节令 |
| `pillars.year|month|day|hour` | 干支、十神、藏干（layer：本气 / 中气 / 余气，各带十神）、纳音、dayMasterStage（星运：日主在该支）、selfStage（自坐：该干在本支）、isVoid（空亡） |
| `fiveElements` | 明字计数、藏干加权值与占比、method（加权口径） |
| `relations` | 天干、地支的合冲刑害——只表示存在，不代表已合化 / 成局 |
| `shensha / parameters` | 神煞及所在柱；胎元、命宫、身宫、胎息 |
| `appReference` | 应用内简法评估（旺衰分项、格局、喜用倾向），可反驳 |
| `luck` | 顺逆、起运、虚岁口径、各步大运；currentLiuNian；timeline = 今年 ±5 年流年（luckStarts 标交运年） |
| `receipt` | 口径回执：换年换月、子时、真太阳时、节气区间、夏令时、sensitivity（时辰分界 / 交节临界提醒） |

年龄一律为虚岁（出生当年记 1 岁）。合盘 JSON 为 `{ a, b, appCompat }`，a / b 结构同单人。
